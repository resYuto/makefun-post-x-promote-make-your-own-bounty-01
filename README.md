An entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty. The entry is one post on X that
quotes make.fun's post; `POST.json` names that post and `main.ts` copies it to the output directory for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
